# AgendeAqui API

This project is a NestJS based API for the AgendeAqui application. It uses Prisma to access a PostgreSQL database and provides multiple modules for handling doctors, patients and other healthcare related features.

## Request TraceId Middleware & Logging

### Automatic TraceId for Each Request

Every HTTP request processed by this API automatically receives a unique `traceId` (UUID v4), which is:

- **Returned to the client in the response header:**

x-trace-id: 13e0bc8e-682a-4be7-9b8a-3d914a982a08

- **Propagated internally and included in all logs generated by that request.**

This allows for complete traceability:  
**To track all logs related to a specific request, simply use the value of `x-trace-id` from the response header.**

#### Example

**Response header:**

x-trace-id: 13e0bc8e-682a-4be7-9b8a-3d914a982a08

**Log entry:**

```json
{
  "level": "info",
  "message": "Request completed",
  "traceId": "13e0bc8e-682a-4be7-9b8a-3d914a982a08",
  "controller": "PatientController",
  "url": "/api/patient",
  "statusCode": 200,
  "duration": "17ms"
}
```
